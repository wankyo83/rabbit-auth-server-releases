## 0.3.10

- 인증된 브라우저가 보유한 쿠키를 이미지 주소별 도메인·경로·보안 범위에 맞춰 manifest에 추가합니다.
- Mangayomi가 원본 CDN 이미지를 직접 받을 수 있도록 쿠키 문자열만 전달하며 이미지 다운로드·저장·중계는 하지 않습니다.
- 쿠키가 없는 사이트와 이전 확장앱은 기존 URL·User-Agent·Referer 응답을 그대로 사용합니다.

## 0.3.9

- Newtoki의 `PREMIUM EPISODE` 유료 잠금 화면을 즉시 감지합니다.
- 잠긴 회차는 무한 대기나 일반 인증 실패 대신 전용 안내 이미지 1장을 반환합니다.
- 안내 이미지에서 로그인·구매 필요 여부와 관리 화면 WebView에서 무료 전환 시간을 확인하도록 안내합니다.
- 실제 작품 이미지는 계속 앱 또는 Suwayomi가 원본 서버에서 직접 받으며 중계하지 않습니다.
