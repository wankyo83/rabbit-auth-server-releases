# Rabbit 인증 서버 Android 테스트 0.3.0-test7

이 프로젝트는 기존 Windows/Docker 인증 서버나 배포 확장앱을 변경하지 않고 만든 독립 테스트 소스입니다.

## 테스트 범위

- 같은 Android 기기에서 실행 중인 Mihon 계열 앱만 연결
- 서버 주소: `http://127.0.0.1:9898`
- Newtoki/토끼/SBXH 웹툰·만화와 소설 회차 지원
- Blacktoon, Jjaptoon, 11toon, WFWF, Goodtoon, xtoon, 네이버 웹툰 지원
- 기기의 실제 화면 해상도·밀도로 만든 VirtualDisplay WebView 자동 인증 및 이미지 주소 수집
- 인증이 멈춘 경우 작업당 한 번의 짧은 가상 터치 스크롤 수행
- 자동 인증이 끝나지 않을 때 같은 쿠키를 사용하는 수동 인증 화면 제공
- 원본 사이트의 `이미지 처리 중인 회차입니다` 문구 감지 시 기존 안내 이미지 반환
- 독립 VirtualDisplay WebView 두 개로 동시 작업 2개
- 접속 키를 공백 없는 4~128자의 영문·숫자·기호로 변경 가능
- 인증과 이미지 주소 확보만 서버가 처리하고 Mihon이 원본 주소로 직접 연결
- 이미지 중계 설정과 이미지 중계 API는 제공하지 않음
- VirtualDisplay WebView를 서버 시작 시 미리 준비하고 작업 후 빈 화면으로 초기화해 재사용
- 예상 이미지 수가 확인되면 즉시 반환하고, 예상 수가 없는 사이트는 0.6초 동안 목록이 안정되면 반환
- 가상화 뷰어는 스크롤마다 보이는 이미지 주소를 페이지 번호별로 누적한 뒤 전체 목록을 반환
- 배터리 소모를 줄이기 위해 WakeLock은 사용하지 않음
- GitHub의 Android 전용 업데이트 정보를 확인하고 APK 다운로드·SHA-256 검증·설치 화면 연결

## 사용 순서

1. APK를 설치하고 알림 권한을 허용합니다.
2. 앱에서 `서버 시작`을 누릅니다.
3. Mihon의 해당 확장앱 설정에서 외부 인증 서버를 켭니다.
4. 서버 주소에 `http://127.0.0.1:9898`을 입력합니다.
5. Android 서버 앱에 표시된 접속 키를 복사해 확장앱에도 입력합니다.
6. `연결 확인` 후 회차를 엽니다.
7. 자동 인증 실패 알림이 뜨면 서버 앱의 `인증 화면 열기`에서 사이트 확인을 마치고 Mihon에서 다시 시도합니다.
8. 이후 새 버전은 앱 하단의 `업데이트 확인`에서 내려받고 설치합니다.

## 알려진 테스트 한계

- 화면이 꺼지거나 Android 절전 정책이 앱을 중지하면 서버도 중단될 수 있습니다.
- 재부팅 후 자동 시작하지 않습니다.
- 이번 테스트판은 로컬 루프백에만 바인딩하므로 다른 기기에서는 접속할 수 없습니다.
- 실제 WebView 인증 성공 여부는 기기의 Android System WebView 버전과 사이트 인증 정책에 영향을 받습니다.
- APK는 테스트용 디버그 인증서로 서명했습니다.
- Android 보안 정책에 따라 업데이트 설치 전 사용자의 최종 승인이 필요합니다.

## 빌드

```powershell
.\gradlew.bat clean assembleRelease lintRelease
```
