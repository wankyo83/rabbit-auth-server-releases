# Rabbit 인증 서버 Android 설치 설명서

Rabbit 인증 서버 Android판은 **같은 Android 태블릿에 설치된 Mihon 전용**입니다. Windows 또는 NAS 없이 태블릿 안에서 사이트 인증을 처리하고, 확인된 이미지 주소를 Mihon 확장앱에 전달합니다. 이미지 파일 자체는 저장하거나 중계하지 않습니다.

## 요구 사항

- Android 8.0 이상
- Mihon과 지원 확장앱이 같은 기기에 설치되어 있어야 함
- 최신 Android System WebView 권장
- 서버 주소: `http://127.0.0.1:9898`
- 동시 인증 작업: 2개

같은 기기 안에서만 통신하므로 포트포워딩과 Tailscale은 필요하지 않습니다.

## 최초 설치

1. GitHub에서 `RabbitAuthServer-Android-0.3.0-test10.apk`를 다운로드합니다.
2. 브라우저 또는 파일 앱에 `알 수 없는 앱 설치` 권한을 허용합니다.
3. APK를 열어 설치합니다.
4. 앱을 실행하고 알림 권한을 허용합니다.
5. `서버 시작`을 누릅니다.

앱을 삭제하면 접속 키와 앱 설정도 삭제될 수 있습니다. 업데이트할 때는 기존 앱을 삭제하지 말고 새 APK를 그대로 설치하세요.

## Mihon 확장앱 연결

1. Mihon에서 사용할 확장앱의 `설정`을 엽니다.
2. `외부 인증 서버 사용`을 켭니다.
3. 서버 주소에 `http://127.0.0.1:9898`을 입력합니다.
4. Android 인증 서버 앱의 접속 키를 복사해 확장앱에도 같은 값으로 입력합니다.
5. `연결 확인`을 누릅니다.
6. `연결 정상`, 서버 버전, `동시 작업 2개`, `주소 제공 방식`이 표시되는지 확인합니다.

외부 인증 서버 설정은 확장앱별로 저장됩니다. 여러 확장앱을 사용한다면 각 확장앱에서 한 번씩 설정해야 합니다.

## 앱 업데이트

앱을 열면 GitHub에서 Android판 최신 버전을 자동으로 확인합니다. 새 버전이 있을 때만 앱 하단의 `앱 업데이트`에 표시됩니다.

1. `업데이트 확인`을 누릅니다.
2. 새 버전이 표시되면 다운로드 버튼을 누릅니다.
3. 앱이 APK를 다운로드하고 SHA-256을 검증할 때까지 기다립니다.
4. 처음 한 번은 Rabbit 인증 서버의 `알 수 없는 앱 설치` 권한을 허용합니다.
5. Android 설치 화면에서 `업데이트`를 누릅니다.

Android 보안 정책상 마지막 설치 승인은 자동화할 수 없습니다. 업데이트 APK는 기존 설치본과 동일한 서명으로 배포되며, 앱을 삭제하지 않고 덮어써야 접속 키가 유지됩니다.

## 사용 방법

- 서버 상태가 `실행 중 · 127.0.0.1:9898 · 동시 작업 2개`인지 확인합니다.
- Mihon에서 회차를 열면 인증 서버가 보이지 않는 WebView로 인증하고 이미지 주소를 반환합니다.
- 서로 다른 회차 요청 두 개까지 동시에 처리합니다.
- 자동 인증이 끝나지 않으면 앱의 `인증 화면 열기`를 눌러 사이트 확인을 완료한 뒤 Mihon에서 새로고침합니다.

## 문제 해결

### 연결 확인 실패

- Android 인증 서버 앱에서 서버가 실행 중인지 확인합니다.
- 주소가 정확히 `http://127.0.0.1:9898`인지 확인합니다.
- 인증 서버와 확장앱의 접속 키가 같은지 확인합니다.

### 화면이 꺼진 뒤 서버 중지

제조사 절전 정책에 따라 앱이 중지될 수 있습니다. Android 설정에서 Rabbit 인증 서버의 배터리 사용을 `제한 없음` 또는 `최적화 제외`로 설정하세요.

### 인증 화면이 반복해서 필요함

- Android System WebView와 Chrome을 최신 버전으로 업데이트합니다.
- `인증 화면 열기`에서 사이트 확인을 끝낸 뒤 Mihon에서 회차를 다시 엽니다.
- 사이트 로그인이나 유료 콘텐츠 확인이 필요한 회차는 자동으로 처리되지 않을 수 있습니다.

## 보안 참고

- 서버는 `127.0.0.1`에만 열리므로 같은 태블릿의 앱만 접속할 수 있습니다.
- 접속 키가 포함된 요청 내용은 로그에 기록하지 않습니다.
- 업데이트 정보와 APK는 HTTPS로만 받습니다.
- 다운로드 주소를 공식 GitHub 저장소로 제한하고 APK SHA-256을 확인합니다.
- Android는 설치 시 기존 앱과 새 APK의 서명이 같은지 다시 확인합니다.
