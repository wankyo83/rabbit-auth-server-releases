# Rabbit 인증 서버 Windows 0.4.11 검증 보고서

검증일: 2026-09-09 (Asia/Seoul)

## 변경 범위

- 작은 창에서 전체 설정 페이지를 세로 스크롤할 수 있게 수정했습니다.
- 서버 주소 카드는 충분한 높이를 유지하고, 주소 목록만 별도로 스크롤되게 수정했습니다.
- 창 최소 크기를 720×480으로 낮췄습니다.
- 네트워크 주소 탐지·정렬, `0.0.0.0` 바인딩, 접속 키 인증, 방화벽 처리, 업데이트 로직은 변경하지 않았습니다.

- WinForms 레이아웃 스모크: 통과

  - 1024×600
  - 800×600
  - 1280×900
- 각 화면에서 전체 페이지 스크롤, 주소 목록 내부 스크롤, 주소 5개 생성, 마지막 `주소 복사` 버튼 접근, 하단 `업데이트 확인` 버튼 접근을 확인했습니다.
- 주소 목록 뷰포트 높이: 144px
- 실제 로컬 주소 탐지: `192.168.0.57` 포함 5개
