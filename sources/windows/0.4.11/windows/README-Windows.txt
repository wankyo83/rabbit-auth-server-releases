Rabbit 인증 서버 0.4.11 · Windows x64 정식 배포판
=========================================

1. ZIP 전체를 원하는 폴더에 압축 해제합니다.
2. RabbitAuthServer.exe를 더블클릭합니다. EXE만 따로 옮기면 안 됩니다.
3. 포트는 기본 9870, 접속 키는 본인이 정한 4자 이상을 입력합니다.
   숫자·영문·기호 가능, 공백 불가. 짧은 숫자보다 긴 키를 권장합니다.
4. '서버 시작'을 누르고 '정상 실행 중' 표시를 기다립니다.
5. 주소 목록에서 휴대폰/스와요미가 접근할 수 있는 주소를 더블클릭해 복사합니다.
6. 확장앱에서 외부 인증 서버 ON → 서버 주소와 같은 키 입력 → 연결 확인.

Node.js, Python, Docker, .env 파일, PowerShell 명령은 필요하지 않습니다.
Windows 10/11 x64 및 .NET Framework 4.8 환경용입니다. ARM/32비트용이 아닙니다.
일반 사용자 권한으로 실행하며 시스템 시작 서비스나 자동 실행을 설치하지 않습니다.
실행 중 PC의 Windows 로그인 상태를 유지해야 합니다. 로그아웃·절전·종료하면 멈춥니다.

주소 선택
---------
- 같은 Wi-Fi/LAN: http://윈도우PC의LAN주소:9870
- Tailscale: http://윈도우PC의Tailscale주소:9870
- PC 이름이나 Tailscale MagicDNS 이름도 사용할 수 있습니다. 서버에 별도 등록하지 않습니다.
  10.x.x.x 등 사용자별 LAN IP도 특정 대역으로 제한하지 않으며 접속 키는 항상 필요합니다.
  이름을 입력한다면 요청을 보내는 기기/도커에서 그 이름을 해석할 수 있어야 합니다.
- 같은 PC에 설치한 앱: http://127.0.0.1:9870
- NAS의 Suwayomi 도커: NAS주소가 아니라 이 Windows PC의 접근 가능한 LAN IP를 입력.
  이름(nas, PC이름)이 컨테이너 내부에서 해석되지 않을 수 있으므로 IP를 우선 사용하세요.
- 127.0.0.1은 다른 휴대폰이나 다른 도커에서 이 PC를 가리키지 않습니다.
- 인터넷 공유기 포트포워딩은 LAN/Tailscale 사용에 필요하지 않습니다.
- 주소 목록 위에 `방화벽 허용됨`, `일부 네트워크 차단` 또는 `방화벽 차단됨`이 표시됩니다.
  차단 상태라면 `방화벽 허용`을 누르고 Windows 관리자 권한 요청을 승인하세요.
  인증 서버에 포함된 전용 runtime/node.exe만 개인·공용 네트워크의 허용 앱으로 등록하며
  Windows 방화벽 자체를 끄지 않습니다. 포트를 변경해도 다시 등록할 필요가 없습니다.
- 네트워크/IP가 바뀌면 서버를 중지 후 다시 시작해 주소 목록을 갱신하세요.
  화면의 주소 목록은 편의를 위한 표시일 뿐 허용 목록이 아닙니다.
  방화벽 앱 허용은 DNS·Tailscale 연결·라우팅을 자동 설정한다는 뜻이 아닙니다.

관리 화면과 숨은 브라우저
------------------------
'관리 화면'에서 사용자 이름 lab, 비밀번호에 설정한 접속 키를 입력합니다.
실제 Chromium은 일반 데스크톱이 아닌 프로그램 전용 Win32 데스크톱에서 실행됩니다.
headless 전환이나 0×0 창이 아닙니다. Chromium 샌드박스는 Windows에서 켜 둡니다.
이 전용 데스크톱은 Docker/VM 같은 OS 격리 또는 보안 경계를 뜻하지 않습니다.
관리 화면의 '인증 화면 보기'는 선택한 회차 탭만 보여 주며 클릭·스크롤·텍스트 입력이 가능합니다.
개인 Windows 바탕화면, 다른 Chrome/Edge 창, 개인 브라우저 프로필은 공유하지 않습니다.
직접 입력이 필요한 사이트에서는 사용자가 확인해야 하며 자동 통과를 보장하지 않습니다.
사이트 계정 비밀번호, 결제 정보 등은 입력하지 마세요. 접속 키를 아는 서버 사용자는
다른 활성 회차의 화면을 볼 수 있습니다. 신뢰하는 사용자끼리만 사용하세요.

동작
----
- 확장앱이 보낸 회차 주소를 사용합니다. Goodtoon과 Newxtoon을 포함한 지원 도메인 계열을 처리합니다.
- Newxtoon 이미지는 해당 회차의 정확한 주소를 Referer로 전달합니다.
- 회차마다 별도 컨텍스트, 동시 인증 2개. 초과 요청은 회차 단위로 대기합니다.
- 인증 후 이미지 주소·페이지 순서를 전달하고 해당 회차 브라우저는 종료합니다.
- 실제 이미지 다운로드는 확장앱/스와요미가 직접 수행합니다. 이미지 중계 서버가 아닙니다.
- Newtoki 유료 잠금 회차는 무한 대기하지 않고 안내 이미지 1장으로 표시합니다.
  무료 전환 시간은 관리 화면의 인증 화면 보기에서 확인하세요.
- 관리 화면의 JPEG 화면 미리보기는 수동 조작용이며 회차 이미지 다운로드 중계가 아닙니다.
- 한 회차를 닫거나 다른 소스를 열어도 다른 진행 회차를 취소하지 않습니다.
- 외부 서버 OFF는 기존 확장앱 동작입니다. 소스 ID/라이브러리/다운로드를 바꾸지 않습니다.
- Windows 서버 시작 성공과 특정 사이트 인증 성공은 다릅니다.
- Docker에서 성공한 사이트도 Windows의 네트워크/브라우저 환경에 따라 실패할 수 있습니다.

종료와 데이터
-------------
'트레이로 숨기기'는 설정 창만 숨깁니다. '서버 중지' 또는 종료 확인은 서버와 브라우저를 닫습니다.
설정/로그/사이트별 쿠키는 %LOCALAPPDATA%\RabbitAuthServer 에 저장됩니다.
키는 Windows 현재 사용자용 DPAPI로 암호화하여 저장합니다. 다른 사용자/PC로 옮기면 재입력합니다.
파일 접근은 현재 Windows 사용자 및 SYSTEM으로 제한합니다. 개인 Chrome 프로필은 쓰지 않습니다.
쿠키는 사이트별로 저장하지만 유효기간을 임의로 연장하지 않습니다.
`새 버전 자동 알림`은 기본 ON입니다. 실행 약 3초 뒤와 마지막 정상 확인으로부터 24시간마다
백그라운드로 확인합니다. 최신 버전이 있으면 현재/최신 버전을 보여 주고 사용자 승인을 받은 뒤
다운로드·검증·설치·재시작합니다. 같은 버전을 나중에 선택한 경우 반복해서 알리지 않습니다.
오른쪽 아래의 `업데이트 확인`은 자동 알림 설정과 관계없이 언제든 수동으로 확인합니다.
자동 확인 실패는 작업을 방해하는 오류 창을 띄우지 않으며 한 시간 뒤 다시 시도합니다.
사용자 데이터는 같은 경로에 남습니다.
삭제하려면 서버를 종료한 뒤 설치 폴더를 삭제하면 됩니다. 쿠키까지 지우려면 위 사용자 데이터
폴더를 별도로 삭제해야 합니다. 기존 NAS 도커 데이터와는 독립적입니다.

보안과 배포
-----------
이 버전은 코드 서명 인증서가 없는 배포판입니다. SmartScreen/보안 프로그램의 경고가 나올 수
있지만, 경고를 무시하거나 백신을 끄는 것을 권장하지 않습니다. 출처와 SHA-256을 확인하세요.
0.0.0.0으로 수신하며 모든 정상 형식의 목적지 이름/IP를 받되 접속 키 검증은 유지합니다.
잘못된 Host 형식과 다른 출처의 브라우저 요청은 거부합니다. 네트워크 자체를 격리하지 않습니다.
HTTP는 키를 암호화하지 않습니다. 신뢰된 LAN/Tailscale용으로 사용하세요.
인터넷 공개는 별도 HTTPS와 접근 통제가 필요하며 기본 배포 범위가 아닙니다.
동봉한 checksums.json은 파일 훼손 검사 용도이며 게시자의 디지털 서명을 대신하지 않습니다.
