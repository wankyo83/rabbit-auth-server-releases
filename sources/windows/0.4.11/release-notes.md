## 0.4.11

- 작은 창에서도 전체 화면을 세로로 스크롤해 서버 주소와 하단 안내에 접근할 수 있습니다.
- 서버 주소가 많은 환경에서는 주소 목록 안쪽 스크롤로 모든 주소와 복사 버튼을 사용할 수 있습니다.
- 큰 창의 기존 카드 디자인과 서버·방화벽·접속 키·자동 업데이트 동작은 그대로 유지합니다.

## 0.4.10

- Newtoki의 `PREMIUM EPISODE` 유료 잠금 화면을 즉시 감지합니다.
- 잠긴 회차는 무한 대기나 일반 인증 실패 대신 전용 안내 이미지 1장을 반환합니다.
- 안내 이미지에서 로그인·구매 필요 여부와 관리 화면에서 무료 전환 시간을 확인하도록 안내합니다.
- 실제 작품 이미지는 계속 앱 또는 Suwayomi가 원본 서버에서 직접 받으며 중계하지 않습니다.
